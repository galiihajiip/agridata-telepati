# Pernyataan Orisinalitas: Placeholder

TELEPATI 8.0 AgriData Intelligence Race mensyaratkan pernyataan orisinalitas
bertanda tangan basah sebagai bagian dari paket submission. Penyusunan,
penandatanganan, dan pengiriman dokumen tersebut berada di luar cakupan
repository ini dan harus ditangani langsung oleh tim.

Berkas ini ada agar kewajiban tersebut tercatat pada jejak audit, bukan
hilang tanpa keterangan. Lihat
[`artifacts/audit/final_submission_audit.md`](../artifacts/audit/final_submission_audit.md)
bagian DOCUMENTS.

## Daftar periksa (diselesaikan oleh tim, tidak dapat diverifikasi otomatis)

- [ ] Dokumen pernyataan orisinalitas diperoleh dari panitia
- [ ] Diisi dengan nama tim, nama anggota, dan judul submission yang benar
- [ ] Ditandatangani oleh seluruh pihak yang disyaratkan, yaitu ketua tim,
      anggota, dan dosen pembimbing, sesuai templat resmi
- [ ] Dikirim melalui kanal resmi kompetisi bersama tautan repository,
      notebook, dan bobot model

## Bagian orisinalitas yang sudah dapat diverifikasi dari repository

Aspek orisinalitas yang dapat diperiksa secara teknis sudah tercakup pada
audit kepatuhan, yaitu tanpa dataset eksternal, tanpa *external pretrained
weights*, dan tanpa pemrosesan dataset menggunakan LLM maupun API. Rinciannya
berada pada bagian DATA dan MODEL di
[`artifacts/audit/final_submission_audit.md`](../artifacts/audit/final_submission_audit.md).

Dokumen bertanda tangan itu sendiri merupakan artefak manusia di luar
repository, sehingga tidak dapat dan tidak boleh diklaim selesai oleh proses
otomatis mana pun.
